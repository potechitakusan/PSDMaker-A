# トークン節約方針

通常の実行は[AGENTS.md](../AGENTS.md)に従う。この文書は方針見直し時のみ参照する。

- 速度より節約を優先し、通常は単独実行する。サブエージェントは利用者の明示依頼時のみ使い、重複作業を避ける。
- 完了通知を優先する。待機は原則60秒（環境の上限内）とし、頻繁な状態確認を避ける。
- 読込・ログ・説明は必要箇所に絞る。有効なキャッシュを再利用し、変更や未解決事項がなければ再読込・再検証しない。
- モデル・推論設定、必要な画像解像度、品質基準を維持する。全領域・位置合わせ・背景・実PSDの読み戻し・全比較画像の確認と、再構築後のレビューを省略しない。所見と画像根拠は保存する。
- API専用のキャッシュ・推論変更・非同期実行設定は、ローカルPSD CLIやAGENTS.mdへ導入しない。
- トークン削減率や品質維持の効果は、実測なしに断定しない。
