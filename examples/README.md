| ファイル | 内容 |

| coloring/output.psd | 第2機能の着色PSD。1024×1536、103描画レイヤー＋48フォルダ |

第2機能は同じキャラクターが手を振る別ポーズの開発試験です。2026-09-27に新しい参照PSDから再着色しました。領域抽出・意味割当・照明案を新しいジョブで作成し、第1機能のBase色を継承しています。参照画像のポーズへ線画を変形していません。

影・光は、新しい下塗りと参照PSDの完成色を渡して作ったAI照明案の明度から生成しています。`lighting.color_model: source_tones`で素材ごとの影色・光色を決め、`tone_mapping: absolute`で照明案の明るさを使います。ガイドの線や色をPSDへ貼り付けてはいません。

実PSDの35個のBaseレイヤーと参照色の一致、二値化した入力線の画素保持、色替え、背景、素材別の明暗・彩度を確認しました。Python着色結果からのPSD読み戻しはMAE 0.0541、最大チャンネル差1です。別ポーズの参照画像やAI画像との一致点数ではありません。

制約: 上向きのうさぎの耳は内側の線が大きく開いているため内側もクリーム色です。髪先の開いた線の間は背景色になります。髪・黒布は参照より暗め、白布・肌は明るめで、照明の細部にもずれが残ります。うさぎの黒目や眉は主に線レイヤーにあるため、Baseだけの色替えには限界があります。参照PSDには外周の細い白縁や抽出線の塗り跡が残ります。Photoshop／CLIP STUDIO PAINTでの実アプリ確認は行っていません。

プレビューJPGは実PSDから作成し、EXIF/XMP・コメントを付けずに保存しています。
