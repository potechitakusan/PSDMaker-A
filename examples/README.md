両方式は `output/output.psd` と隣接JSONからBaseを継承しています。白布・髪は通常明部候補、肌・黒布は中間色候補を選び、下塗りが影色へ沈む問題を軽減しました。

第1機能の参照は手を振るポーズ、第2機能は両手を下げてうさぎを抱える別ポーズです。新線画を通常のprepare-coloringで領域分けし、一覧画像を目視して素材を新規に割り当てました。局所隙間補助後の445領域を、32前景パーツ＋背景へまとめています。参照のマスク・領域番号・座標はコピーしていません。

**今回の線画生成は、機能説明用の作例を作るためにimagegenを使ったものです。通常は利用者が線画を用意し、第2機能が線画を自動生成することはありません。** 着色、局所補助、PSD保存と事後チェックには通常の第2機能のCLIを使用しました。

imagegen方式は、新しい下塗りと参照PSDの完成色をCodex組込みimagegenへ渡して生成したガイドの明度を使います。`color_model: source_tones`、`tone_mapping: source_levels`で素材ごとの明暗と色を参照へ合わせました。ガイドの線や色をPSDへ直接貼っていません。

法線マップ方式は、新しい別ポーズの着色再構成から同一格子へ法線を新規推定し、既定の左上手前（光源1）から照明を計算しました。imagegen方式の着色結果を推定入力にした比較例であり、imagegenから独立した評価ではありません。`source_tones` と `source_ramp` で素材別に明暗幅・色を合わせています。保存PSDはこの光源で固定されたBase/Shadow/Highlightです。法線配列は公開例に含めていません。50光源の切替は法線を登録した作業jobとプレビュー画面で利用できます。

両PSDの32前景Baseが参照JSONのRGBを保持すること、新規割当マスクとの一致、入力二値線の完全保持、影/光の素材外画素0を検証しました。全色替え・素材・背景・明暗比較画像を目視し、事後レビューは制約付き完了。Python着色目標からのPSD読み戻しMAEはimagegen方式0.06347、法線方式0.06991、最大チャンネル差は両方1です。元絵の印象や影形状の再現点数ではありません。

制約: 法線方式は鼻の点状影、髪の艶、瞳の反射が元絵と異なるため、主例にはimagegen方式を採用しました。imagegen方式にも虹彩の明度差や細線近傍の照明ずれが残ります。下瞼の開いた線で白目の一部が肌につながる箇所は局所補助後も残り、大きな色替え時に追加修正が必要です。入力線の微小ジャギーと線主体の眉・黒目、参照由来のうさぎのフラットな色部も残ります。大きな色替えでは影・光の色も調整が必要です。Photoshop／CLIP STUDIO PAINTでの実アプリ確認は行っていません。

プレビューJPGは実PSDから作成し、EXIF/XMP・コメントを付けずに保存しています。

## トーン版

### Qwen作例

| ファイル | 内容 |
|---|---|
| manga/reference.jpg | 今回指定された第1機能の入力カラー画像の公開用JPG。カラー版とは別の原画 |
| manga/output.psd | QwenImage2.1再描画・Manga Line Extractionによる第1機能のトーンPSD。利用者指定の調整版。2793×4096、600dpi、26描画＋15フォルダ |
| manga/tone_reference.json | 上記の調整済みPSDと一組の9素材のトーン情報。濃度・ベタ可否・意味名・階層・適用済みの網設定を含む |
| manga/preview.png | 第1機能PSDの原寸トーン化プレビュー |
| manga/lineart.png | 第1機能PSDから取り出した線画単独PNG |
| manga_transfer/lineart.png | QwenImage2.1で作った肩ひもに手を添える別ポーズ線画の二値化PNG。実PSDの線レイヤーと一致 |
| manga_transfer/preview.png | 素材別濃度を引き継いだ第2機能PSDの原寸プレビュー |
| manga_transfer/output.psd | 参照の素材濃度・網設定を変えずに別線画へトーンを貼った第2機能のPSD。832×1248、18描画＋16フォルダ |
| manga_transfer/tone_reference.json | 上記PSDと一組の9素材のトーン情報。さらに別線画への引き継ぎに使用可能 |

第1機能（トーン版）はカラー画像を入力し、トーン化したPNG・PSDを出力します。第2機能（トーン版）はその素材情報を別線画へ引き継ぎますが、出力品質は検証中です。manga_transferのファイルは検証用として保持しています。今回のトーン版は利用者が指定した別のカラー原画から作り直しており、カラー版作例は変更していません。第1機能の画像比較は [ルートREADMEのトーン版作例](../README.md#作例トーン版) を参照してください。

第1機能は指定された海辺のカラー画像（2793×4096px）からQwen-Image 2.1 Turboで再描画しました。生成は既定の1Mpx・seed 1・8ステップ、結果は832×1248pxです。線はManga Line Extractionで元画像から抽出し、原画を変形せず生成側を原寸へ位置合わせしています。抽出線の隙間で人物と背景がつながったため、同じQwenで同じポーズの補助線画も作り、塗り分け境界だけに使用しました。全領域を目視し、顔・瞳・マフラー端を局所修正して286領域を9パーツへ整理しています。補助線画は完成PSDの線へ置き換えていません。

第2機能の検証用ファイルは、調整前の第1機能PSDとJSONを参照して作ったものです。今回差し替えた調整済みPSDの濃度を使った再制作はしていません。同じカラー原画からQwenImage2.1で作った別ポーズ線画へ素材・役割を新しく割り当て、初期120領域を目視し、薄い線を塗り分け境界だけに利用して顔・耳・マフラーのフリンジの結合を補助。180領域を9パーツへ整理しています。出力線の二値化閾値192と線の画素は維持しました。局所の境界補助は作例用のPython処理で、トーン調整画面のブラシ機能ではありません。元ポーズの座標・領域番号・マスクは移していません。

**別ポーズの線画生成は今回の作例制作のために行いました。通常は利用者が線画を用意し、第2機能が自動生成することはありません。** 上記のQwen作例の再描画と別ポーズ線画にはQwenImage2.1を使い、imagegenは使っていません。

第1機能の初回出力は `manga_tone.DEFAULT_SETTINGS` を使いました。現在の公開PSDは、利用者から指定された調整版をそのまま採用しています。各素材の指定はbase:auto／shadow:auto／highlight:white／beta:trueを維持し、素材濃度は調整後の設定から自動判定されています。Codexによる追加の数値調整はしていません。第2機能は調整前の参照濃度・ベタ可否・網設定を継承したままです。意味分類・境界の修正と、新線画へ影などの役割を割り当てる作業は行っています。

利用者の指定に従い、空・雲・海・波を「背景」1パーツにまとめています。背景の影とハイライトは別レイヤーです。紙色になった白い部分を、編集できる白ハイライトレイヤーへ分離しています。この分離自体はトーン数値・素材濃度・合成画素を変えません。現在の調整済みPSDでは背景のベタはなく、影とハイライトの2層です。背景単独と影・ハイライトの各画像も実PSDから確認しています。

第1機能の調整済み設定はMangaScreen方式のdots、画像幅基準200列、白境界0.80、黒境界0.20、薄トーン0.18、濃トーン0.42、gradation 0、線閾値0.35、白抜き0.4、小領域600、ベタ最小面積40・最小比率0.005、600dpiです。初回からの変更は黒境界・gradation・線閾値・dpiの4項目です。プレビューと線画PNGにも600dpiを記録しています。第2機能は従来の黒境界0.30、gradation 1.0、線閾値0.30、dpi未指定を維持しています。

200はLPIではありません。MangaScreen方式では画像幅で網間隔が決まり、dpiは解像度情報です。第1機能の網間隔は13.965px、第2機能は4.16pxで、第2機能には5px未満の警告が出ています。原寸PNGを100%で確認してください。

両例とも線・ベタ・ホワイト・パーツ別トーン、影／光／ベースOFF、1:1網点、素材一覧、位置合わせ、差分を全確認し、事後レビューは制約付き完了です。原寸PNGは実PSDの読み戻しと全画素一致。第2機能の線レイヤーは入力の二値化線と完全一致し、領域を分ける仮の補助線を含みません。PSD読み戻しのMAEと最大チャンネル差は両例とも0です。Pythonの描画目標に対する値で、カラー原画や別ポーズの形・陰影の再現率ではありません。

制約: 第1機能の線距離は再描画約4.75px・抽出線約3.39px、境界用Qwen線画約4.93pxで、細部の位置差が残ります。肌の陰影などは省略され、髪・コートの粒状の跡が線レイヤーにも混入しています。線単独の編集品質には制約があります。マフラー端・目元・髪縁のマスクにも局所的な誤差が残ります。第2機能には細線・チェック柄の途切れ、フリンジの一部と袖の結合、細かな網の不均一さ、ベタに埋もれる内部線があります。夕日の反射や元の陰影形状は自動移植しません。今回の差し替えでは利用者指定PSDの描画を変更していません。Photoshop／CLIP STUDIO PAINTでの実アプリ確認は行っていません。

公開PNGは画素と解像度情報だけで保存し、PSDのリソースとJSONの意味記述も確認しています。調整済みPSDにはソフトウェアのバージョン情報と解像度だけがあり、作成者名・EXIF/XMP・位置情報・ローカルパスは検出されませんでした。レイヤー名も素材・役割の名前です。PSDは指定ファイルとバイト単位で一致し、JSONのPSD名・ハッシュ・設定も更新済みです。既存のカラー版ファイルは変更していません。PSDと同じフォルダのJSONを一組で保管すれば、制作時のworkフォルダがなくても新しい線画へ引き継げます。実際の準備例は [第2機能（トーン版）の手順](../docs/TONE_TRANSFER_WORKFLOW.md#付属作例を参照にする) を参照してください。

### imagegenのみの作例

同じ海辺のカラー原画を使う第1機能の比較例です。利用者の指定により、線画・再描画ガイド・背景削除版をすべてCodex組込みimagegenで生成しました。Qwenの再描画・線抽出・補助線・マスク・調整値は流用していません。既存のQwen作例、トーン第2機能、カラー版の成果物は変更していません。

拡大不要の指定に従い、原画の作業コピーを生成線画と同じ1036×1519pxへ縮小しました。元画像は不変です。両PSDともこのサイズで、25描画レイヤー＋17フォルダ、9パーツ。Qwen作例とは出力サイズや設定が異なるため、同じ条件でのモデル性能比較ではありません。

制作は[トーン版の作業手順](../docs/MANGA_WORKFLOW.md)に従っています。原画と線画からimagegenで再描画ガイドを生成し、原画から別途生成した背景削除版のalphaを位置合わせして被写体と背景を分割しました。削除版のRGBを原画・陰影・線へ貼り込む処理はありません。髪の隙間や持ち手内の背景、下端の欠落を局所修正し、全519領域・15枚の領域一覧を目視して新しく素材を割り当てました。背景・髪・肌・瞳・マフラー・コート・リュック・肩ひもと持ち手・ボタンの9パーツです。空・雲・海・波は背景1パーツで、影と紙色の白ハイライトを別レイヤーにしています。

`input_lineart.png`は生成された線画そのものの画素です。完成PSDの線は、位置合わせした入力線画と再描画ガイド由来の細線を組み合わせる現行の処理を通っています。このため、PSDから取り出した`lineart.png`とは異なり、完成線にはガイド由来の粒状跡も含まれます。

既定値版は`manga_tone.DEFAULT_SETTINGS`、全パーツbase:auto／shadow:auto／highlight:white／beta:trueを維持しています。調整版は同じ入力・位置合わせ・意味マスクで複数案を比較し、次の差だけを適用しました。背景の白ハイライト分離は両版共通のレイヤー構造で、数値調整ではありません。

| 設定 | 既定値版 | Codex調整版 | 調整の狙い |
|---|---:|---:|---|
| 黒境界 `black_point` | 0.30 | 0.16 | 広いベタを抑える |
| `gradation` | 1.0 | 0 | 濃度の段差を明確にする |
| 線閾値 `pen_threshold` | 0.30 | 0.40 | 薄い生成ノイズを抑える |
| 白抜き `white_lines` | 0.40 | 0.20 | 広い白抜きを抑える |
| 画像幅基準の網点列数 `screen_lines` | 200 | 160 | この出力サイズで網を少し粗くする |
| 解像度情報 `dpi` | 未指定 | 600 | PSD・PNGへ解像度情報を付ける。画素数は不変 |
| コート・背景の `beta` | true | false | ベタをトーンへ変え、コートのしわを見せる |

白境界0.80、薄トーン0.18、濃トーン0.42、小領域600、ベタ最小面積40・最小比率0.005は共通です。他のパーツ指定も既定のままです。方式はnode、形式はdots。200/160はLPIではなく、網間隔はそれぞれ5.18px/6.475pxです。この方式のdpiは解像度情報にだけ使います。通常制作の既定値や自動調整方針を変えたわけではありません。

両PSDについて、線単独・ベタ単独・ホワイト・素材別トーン・背景/被写体単独・影/光/Base OFF・1:1網点・素材一覧・位置合わせ・差分を確認し、事後レビューを制約付き完了としました。PNGはPSDの読み戻しと全画素一致、処理目標に対するMAEと最大チャンネル差は両方0です。JSONは同じフォルダのPSDのハッシュ・サイズと一致し、作業jobなしで読み込めることも確認しました。背景alpha分離と既存トーン工程の関連テスト57件が合格しています。

制約: 原画と生成物の形は完全には一致しません。補正後の線距離は線画約1.79px、再描画約2.76px、背景削除版の被写体内部約2.26pxで、後二者は要注意判定です。これは線間距離の平均で、輪郭の一致率ではありません。髪先・房のマスク、目元の小領域にずれが残ります。既定値版はコートのベタが強く、内部線が埋もれます。調整版は服の形が見やすくなりましたが、線の粒状跡、目元・口元の二重線、チェック柄や雲・波の描き直し差、髪の白抜き縁の粗さは残ります。入力線と再描画の網が干渉する箇所もあり、数値調整だけで解消したものではありません。Photoshop／CLIP STUDIO PAINTでの実アプリ確認は行っていません。

公開PNGには画素と必要なdpiだけを保存し、EXIF/XMP・コメント・生成プロンプトは含めていません。背景削除版の実alphaは保持しています。PSDのリソースはバージョン情報と、調整版のみ解像度情報です。レイヤー名・JSONは素材と役割の記述で、作成者名・位置情報・ローカルパスは含みません。PSDと対応するJSONを一組で保存してください。
